# BPMN 模型說明

## 1 流程文件

流程圖、下載連結及符號說明統一列於 [02 BPMN 流程圖集](../02_BPMN_PROCESS_MODELS.md)。業務條件與例外見 [流程規格](process-spec.md)。

本目錄保留六份 BPMN 2.0 模型及對應 SVG／PNG。圖形使用白底黑線，不以顏色區分任務。

## 2 檢視與編輯

使用支援 BPMN 2.0 的編輯器開啟 `.bpmn`，或直接開啟 SVG／PNG。變更模型後重新排版、驗證並匯出圖檔。

模型為分析用途（`isExecutable=false`），不直接部署至 BPMN 引擎。結構檢核紀錄見 [validation.json](validation.json)。
