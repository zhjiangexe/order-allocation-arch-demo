# Archived Documentation

狀態：歷史資料，不代表現行產品或架構決策。

現行 DDD 戰略文件見 [`docs/ddd/`](../ddd/README.md)。現行技術行為應以程式碼、測試、主 OpenSpec 與未標示
archived／superseded 的操作文件為準。

## 分類

- `legacy-strategy/`：已被後續 DDD 決策或現行模型取代的範圍分析與 roadmap。
- `messaging-evolution/`：Eventuate Tram 對齊過程、gate baseline 與完成的重構 roadmap。
- `implementation-records/`：早期 SR／Demo 實作紀錄。
- `plans/`：已完成的專案計畫、階段 review 與驗收證據。
- `superpowers/`：已完成、被取代或不可再直接執行的 agent plans／specs。
- `snapshots/`：特定時間點產生的 HTML 系統導讀與狀態快照。

封存文件保留原始敘述，不回寫成現行設計。若封存內容與 `docs/ddd/`、主 OpenSpec 或 production code 衝突，
一律以後者為準。
